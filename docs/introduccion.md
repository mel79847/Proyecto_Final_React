# Introducción

**Picnic Rush: Ardillas al picnic** es un juego para dos jugadores en el mismo dispositivo.

Pip y Poppy recorren cuatro zonas de un parque y compiten por alimentos compartidos. Cada alimento vale puntos. En cada turno el jugador elige entre moverse o recoger una comida de su zona. El primer jugador que alcanza 7 puntos gana. Si nadie llega a la meta al finalizar cinco rondas, gana quien tenga más puntos.

La interfaz ocupa toda la pantalla, muestra el turno, posiciones, puntajes, comida disponible, mensajes y resultado final.
