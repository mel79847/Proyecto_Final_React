# Registro de uso de IA

Se utilizó IA como apoyo para:
- proponer una idea de juego compatible con la rúbrica;
- mantener la arquitectura React + Express sencilla;
- proponer estilos CSS y estructura visual;
- revisar casos E2E y documentación.

La estudiante debe revisar, ejecutar y comprender el código antes de la entrega. Durante la defensa debe poder explicar y modificar la implementación.
