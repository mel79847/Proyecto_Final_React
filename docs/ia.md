# Registro de uso de IA

Durante el desarrollo se utilizaron asistentes de inteligencia artificial como herramienta de apoyo.

## Solicitudes realizadas

Se realizaron consultas relacionadas con:

- propuestas de mecánicas para un juego de dos jugadores;
- organización de la arquitectura React + Express;
- explicación de errores de TypeScript, Vite y Git;
- propuestas de organización visual mediante CSS;
- revisión de solicitudes HTTP con `fetch`;
- creación y corrección de pruebas Playwright;
- configuración de GitHub Actions;
- proceso de publicación en Render;
- revisión de la documentación del proyecto.

## Elementos incorporados

Se utilizaron como referencia propuestas para:

- estructura inicial de componentes;
- organización del estado de la partida;
- estructura de endpoints;
- validaciones del backend;
- estilos visuales;
- casos de prueba E2E;
- configuración de workflows;
- documentación técnica.

Las propuestas fueron adaptadas al funcionamiento final de Picnic Rush.

## Verificaciones realizadas

Antes de la entrega se verificó personalmente:

- funcionamiento del juego en el navegador;
- movimiento de Pip y Poppy;
- recolección de alimentos;
- acción de robar;
- cambio de turnos;
- puntuación;
- finalización de partida;
- funcionamiento del backend;
- respuestas de la API;
- construcción mediante `npm run build`;
- ejecución de las pruebas E2E;
- ejecución visual de Playwright;
- validación mediante lint;
- GitHub Actions;
- publicación de frontend y backend en Render.

El código final debe poder ser explicado y modificado durante la defensa.
